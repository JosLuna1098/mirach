# Mirach

A local-first voice assistant daemon. Press a hotkey, talk, get an answer
spoken back — with conversation memory, tool use, and ~3 s round-trip latency.

- **STT:** [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (Whisper
  `large-v3-turbo` on GPU, ~0.3 s once warm).
- **LLM:** [OpenCode CLI](https://opencode.ai) — your choice of model, with the
  full tool ecosystem (bash, file I/O, custom commands).
- **TTS:** [Piper](https://github.com/rhasspy/piper) (local, ~0.3 s).
- **Hotkey trigger:** sends a single `toggle` message to the running daemon
  over a Unix socket. Recording / processing / interrupting are all the same
  keypress.

Built and tested on CachyOS + Hyprland. The pipeline is portable; the desktop
glue (notifications, app launching, hotkey) is currently Linux-only.

---

## How it feels

1. Press `Alt+Z` → short high beep → start talking.
2. Press `Alt+Z` → short low beep → Mirach transcribes, queries the LLM, and
   speaks the answer.
3. While Mirach is thinking or speaking, press `Alt+Z` again → it interrupts
   and starts a new recording immediately.
4. If the LLM takes more than 6 s, a short filler ("one moment", "hmm") plays
   so you know it's still working. It repeats every 6 s until the answer
   arrives.
5. If the daemon dies for any reason, you hear a descending two-tone beep so
   you know to check `journalctl --user -u mirach`.

Each conversation is saved as a markdown file under
`logs/conversations/conversation_<timestamp>.md`, with a `latest.md` symlink
for quick access. `view_conversation.sh` opens the latest one in your
terminal.

## Requirements

- **Python 3.11+** — the only hard prerequisite. The installer handles the rest.
- **PortAudio** — required by `sounddevice` for audio I/O. Pre-installed on
  most Linux desktops; on Debian/Ubuntu: `sudo apt install portaudio19-dev`.
- **NVIDIA GPU with CUDA 12 drivers** — for Whisper STT (CPU mode works but
  adds 2-5 s of latency — see troubleshooting).
- **`notify-send`** — optional, for desktop notifications (mako/dunst/swaync).
- **OpenCode CLI** — the installer sets this up automatically.

## Install

One command — that's it:

```bash
git clone https://github.com/JosLuna1098/mirach ~/mirach && python3 ~/mirach/install.py
```

The interactive wizard will:
- detect your GPU (CUDA) and pre-fill defaults
- ask for your assistant's name, language, and Obsidian vault path
- download a Piper voice
- create a Python virtual env and install all deps
- check/install OpenCode CLI
- render your personal `system_prompt.md` from the template
- install and start the systemd user service

Non-interactive (accept all defaults):

```bash
python3 ~/mirach/install.py --yes
```

### After install

1. `system_prompt.md` is generated by the installer — edit it to personalise.
2. Bind your hotkey to `python3 ~/mirach/trigger.py` — examples below.
3. Run `opencode auth` to configure your LLM provider if you haven't already.

### Manual install

If you prefer to set things up by hand:

```bash
python3 -m venv venv
./venv/bin/pip install -e .
# GPU only:
./venv/bin/pip install "nvidia-cublas-cu12>=12.0" "nvidia-cudnn-cu12>=9.0"

# Download a Piper voice
mkdir -p voices
curl -L -o voices/es_MX-ald-medium.onnx \
  https://huggingface.co/rhasspy/piper-voices/resolve/main/es/es_MX/ald/medium/es_MX-ald-medium.onnx
curl -L -o voices/es_MX-ald-medium.onnx.json \
  https://huggingface.co/rhasspy/piper-voices/resolve/main/es/es_MX/ald/medium/es_MX-ald-medium.onnx.json

cp system_prompt.example.md system_prompt.md && $EDITOR system_prompt.md
cp mirach.service.example ~/.config/systemd/user/mirach.service
# Edit the service file to set MIRACH_VOICE, MIRACH_WHISPER_DEVICE, etc.
systemctl --user daemon-reload && systemctl --user enable --now mirach
```

### Bind the hotkey

Hyprland (`~/.config/hypr/hyprland.conf`):

```
bind = ALT, Z, exec, python3 /home/<you>/mirach/trigger.py
```

Same idea for sway, GNOME custom shortcuts, KDE, etc. — bind whatever
keystroke you like to `python3 <path>/trigger.py`.

### Trying it without a hotkey

```bash
./run_daemon.sh &        # or systemctl --user start mirach
python3 trigger.py       # first press: starts recording
python3 trigger.py       # second press: processes and speaks
python3 trigger.py       # press during playback: interrupts and re-records
```

## Configuration

Every knob is an environment variable. Set them in `mirach.service` or your
shell. Defaults live in [`mirach/config.py`](mirach/config.py).

| Variable | Default | Description |
|---|---|---|
| `MIRACH_BASE_DIR` | `~/mirach` | Project root. |
| `MIRACH_LOCALE` | `en` | UI/audio language. Built-in: `en`, `es`. |
| `MIRACH_WHISPER_LANG` | `es` | Language you speak into the mic (ISO 639-1). |
| `MIRACH_WHISPER_MODEL` | `large-v3-turbo` | Any faster-whisper model name. |
| `MIRACH_WHISPER_DEVICE` | `cuda` | Set to `cpu` if you have no NVIDIA GPU. |
| `MIRACH_WHISPER_COMPUTE` | `float16` | Use `int8` for CPU. |
| `MIRACH_VOICE` | `daniela.onnx` | Filename inside `voices/`. |
| `MIRACH_VOICE_SPEED` | `1.2` | Piper `length_scale` (>1 = slower). |
| `MIRACH_MIC` | `fifine` | Substring match against your mic name. |
| `MIRACH_SAMPLE_RATE` | `48000` | Native rate of your mic. |
| `MIRACH_OPENCODE_MODEL` | `opencode/deepseek-v4-flash-free` | Any OpenCode model id. |
| `MIRACH_OPENCODE_TIMEOUT` | `120` | Seconds before killing OpenCode. |
| `MIRACH_SESSION_IDLE_TIMEOUT` | `120` | Seconds of inactivity before starting a fresh LLM session. |
| `MIRACH_FILLER_DELAY` | `6.0` | Seconds before the first / next filler. |
| `MIRACH_FILLERS` | _(localized)_ | Pipe-separated override: `"hmm.\|hold on.\|one sec."` |
| `MIRACH_SEARCH_REGION` | `wt-wt` | DuckDuckGo region for `web_search.py`. |
| `MIRACH_SOCKET` | `/tmp/mirach.sock` | Path of the daemon's Unix socket. |

### Adding a locale

Append a new entry to `STRINGS` and `FILLERS` in
[`mirach/i18n.py`](mirach/i18n.py), then export `MIRACH_LOCALE=<your-code>`. Strings
missing in your locale fall back to English silently.

## Architecture

```
[Hotkey] → trigger.py ──socket──► daemon (python -m mirach)
                                    │
                                    ├─ AudioRecorder (sounddevice)
                                    ├─ WhisperTranscriber  (faster-whisper, CUDA)
                                    ├─ PiperSpeaker        (piper-tts)
                                    ├─ OpenCodeBackend     (subprocess: opencode run)
                                    ├─ ConversationLog     (markdown per session)
                                    ├─ Notifier            (notify-send + beeps)
                                    └─ SocketServer
```

Source layout:

```
mirach/
  ├── __main__.py       # python -m mirach entry point
  ├── assistant.py      # orchestrator + FSM + shutdown hooks
  ├── audio.py          # thread-safe mic capture
  ├── stt.py            # WhisperTranscriber
  ├── tts.py            # PiperSpeaker (interruptible)
  ├── llm.py            # OpenCodeBackend (interruptible)
  ├── ipc.py            # Unix socket server
  ├── notify.py         # notify-send + beep WAV generation
  ├── conversation.py   # markdown transcript per session
  ├── config.py         # env-var driven config
  ├── i18n.py           # locale strings + fillers
  └── logging_setup.py  # rotating file logger
trigger.py              # standalone — no imports, just sends "toggle"
web_search.py           # DuckDuckGo helper invoked by OpenCode
view_conversation.sh    # opens the latest conversation in a terminal
run_daemon.sh           # launcher: sets up CUDA env + PYTHONPATH
```

## Troubleshooting

**No GPU / CUDA errors.**
Set `MIRACH_WHISPER_DEVICE=cpu` and `MIRACH_WHISPER_COMPUTE=int8`. Transcription
will take 1-3 s instead of ~0.3 s, but it works.

**`Could not load library libcudnn_ops.so.9`.**
faster-whisper needs CUDA 12 runtime libs. They're shipped via pip as
`nvidia-cublas-cu12` / `nvidia-cudnn-cu12`. `run_daemon.sh` adds them to
`LD_LIBRARY_PATH` automatically. If your venv lives elsewhere, set
`MIRACH_BASE_DIR` so the script can find the right `site-packages`.

**Mic not detected.**
Set `MIRACH_MIC` to a substring of your mic name. List with:

```bash
./venv/bin/python -c "import sounddevice as sd; print(sd.query_devices())"
```

**Daemon dies and no beep.**
The two-tone shutdown beep plays on SIGTERM/SIGINT. If you don't hear it, the
process was killed instantly (OOM, SIGKILL). Check `journalctl --user -u mirach`.

**OpenCode not responding.**
Mirach calls `opencode run --model <…>`. Verify it works standalone:

```bash
opencode run --model opencode/deepseek-v4-flash-free "hello"
```

**Notifications not showing.**
Mirach uses `notify-send`. Make sure you have a notification daemon
(mako/dunst/swaync) running.

## Why not [other voice assistant]?

- **Latency.** Most cloud assistants do round-trip in 1-3 s plus network.
  Mirach's STT and TTS stay local; only the LLM call goes out (and even that
  can be local via Ollama-compatible OpenCode backends).
- **Tools.** OpenCode brings shell, file I/O, and your own commands as
  first-class capabilities. The assistant can actually do things on your
  machine.
- **Privacy / control.** No always-on listening. The mic only opens on
  hotkey, recording lives in RAM, transcripts stay on your disk.
- **Hackability.** It's ~700 lines of Python you can read in one sitting.
